# flame-in-freefall

A web-based, SI-powered dashboard for exploring NASA combustion research.

## Technology Stack

### Frontend

- React
- JavaScript
- CSS

### Backend

- Node.js
- Express.js

### Database

- MySQL

## Project Structure

```text
flame-in-freefall/
├── client/       # React frontend
├── server/       # Express backend
├── database/     # SQL schema and seed data
└── docs/         # Project documentation
```

## Getting Started

### 1. Clone the repository

```bash
git clone [text](https://github.com/TasneemChowdhury/flame-in-freefall)
cd flame-in-freefall
```

### 2. Install frontend dependencies

```bash
cd client
npm install
```

### 3. Install backend dependencies

```bash
cd ../server
npm install
```

### 4. Start the backend

```bash
npm run dev
```

The backend runs on:

<http://localhost:5001>

### 5. Start the frontend

In a separate terminal:

```bash
cd client
npm run dev
```
